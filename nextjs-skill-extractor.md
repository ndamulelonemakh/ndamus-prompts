Analyze this project thoroughly and extract reusable “skills” from its implementation patterns.

Context:
This project contains logging and code patterns that I like. I want to identify which patterns are worth turning into reusable skills for future Next.js or similar TypeScript projects.

Definition of a skill:
A skill is a high-frequency, low-variance pattern that is commonly useful across projects. It should be reusable, structured, and predictable enough to document or template.

Your task:
Review the project and identify all important reusable skills we can extract.

Focus especially on:
- Logging patterns
- Error handling patterns
- Request tracing and correlation IDs
- Server actions
- API route handlers
- Middleware
- Authentication and authorization checks
- Validation patterns
- Data fetching patterns
- Database access patterns
- Form handling
- UI state patterns
- TypeScript utility patterns
- Testing patterns
- Configuration patterns
- Deployment or environment patterns

Evaluation criteria:
Only extract a skill if it is:
- Repeated or clearly reusable
- Useful across multiple Next.js or TypeScript projects
- Stable enough to document
- Specific enough to implement
- General enough to transfer to other projects

Avoid:
- Vague observations
- One-off implementation details
- Project-specific business logic
- Overly broad advice
- Skills without concrete examples

Output format:
Use clear headings, tables where helpful, and include code templates for the most important skills.
